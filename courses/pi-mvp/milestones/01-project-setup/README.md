# :fontawesome-solid-circle-1: Project Setup & Configuration

## What You'll Build

A working TypeScript project with a minimal CLI entry point. The agent doesn't do anything yet — but the foundation is in place, and you can run `npm start` to see "Hello agent" printed to your terminal.

## Why This Matters

Before writing any agent logic, you need to decide on your project structure, dependencies, and how the agent will be configured. In pi.dev, this includes TypeScript config, package management, and a configuration system that loads settings from files or environment variables. You'll build a simplified version of that foundation.

## Prerequisites

- :material-nodejs: Node.js 18+ installed
- :fontawesome-solid-box-open: npm or pnpm available  
- :material-pencil-ruler: A text editor (VS Code recommended)
